## 📦 Instalação

### 1. Clonar Repositório

```bash
git clone https://github.com/AlissonHiosaki/server.git
```

### 2. Entrar na Pasta

```bash
cd appweb
```

### 3. Configurar Banco de Dados

Edite o arquivo:

```php
config.php
```

Exemplo:

```php
$host = "localhost";
$dbname = "banco";
$user = "usuario";
$pass = "senha";
```

### 4. Importar Banco

Importe o arquivo:

```sql
database.sql
```

no phpMyAdmin ou MySQL.

### 5. Configurar Permissões

```bash
chmod -R 755 uploads
chmod -R 755 storage
```
